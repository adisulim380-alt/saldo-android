# Изменения Saldo 1.4.0

- Добавлена нативная заставка с иконкой приложения и плавное появление интерфейса.
- В Android-приложении скрывается строка состояния; её можно временно показать системным жестом.
- Ограничена навигация WebView: страница остаётся внутри встроенных ресурсов приложения, произвольные файловые и внешние URL не открываются внутри WebView.
- Отключён доступ WebView к файлам через file-URL и универсальный доступ между источниками.
- Отключено автоматическое резервное копирование Android для финансовых данных; пользовательская JSON-резервная копия остаётся доступна в приложении.
- Исправлено обновление глобальной ссылки на данные после восстановления резервной копии и полного сброса.
- Workflow обновлён до `android-actions/setup-android@v4`.
- Версия Android-пакета синхронизирована с интерфейсом: `1.4.0`.

## Проверки

- JavaScript-блоки проверены на синтаксические ошибки через Node.js.
- XML-файлы разобраны XML-парсером.
- Полная сборка APK не запускалась в этой среде: Android SDK и Gradle здесь не установлены. Её следует проверить через GitHub Actions.
