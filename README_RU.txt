SALDO 1.4 — СБОРКА APK БЕСПЛАТНО С ТЕЛЕФОНА

Что внутри: полноэкранный запуск со скрытой строкой состояния, экран-заставка и плавное появление интерфейса; разделы Главная, Операции и Долги; доходы/расходы, редактирование и удаление записей, категории, месячный бюджет, несколько валют и кошельков, переводы между кошельками, цели накоплений, долги и возвраты, аналитика, календарь, калькулятор, корзина с восстановлением, светлая/тёмная тема, локальное хранение и JSON-резервная копия.

ДАННЫЕ
- Операции автоматически сохраняются локально в хранилище WebView на этом устройстве.
- Данные не отправляются на сервер и не требуют аккаунта.
- Перед переустановкой приложения или очисткой данных Android сделайте резервную копию в Настройки → Скачать резервную копию.
- Резервная копия — файл JSON. Храните его отдельно от приложения.

СБОРКА APK
1. Создайте репозиторий на GitHub, например saldo-android.
2. Распакуйте архив. В корень репозитория загрузите содержимое распакованной папки: папки .github и app, а также build.gradle, settings.gradle и остальные файлы проекта. Не загружайте ZIP как единственный файл репозитория.
3. Откройте вкладку Actions и разрешите запуск workflows, если GitHub попросит.
4. Запустите workflow Build Saldo APK.
5. После успешной сборки скачайте артефакт Saldo-debug-APK.
6. Распакуйте артефакт — внутри будет app-debug.apk. Установите его на Android, разрешив установку из этого источника.

Это debug APK для личной установки, не подписанный релиз для магазина. В проекте нет локального Gradle Wrapper: сборка выполняется в GitHub Actions, где workflow устанавливает Gradle 8.9 и Android SDK. Перед релизом для магазина потребуется отдельная release-сборка и подпись ключом.
